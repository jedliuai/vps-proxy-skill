# Trojan 与聚合订阅实施计划

## 目标

在现有美国单实例上只新增 Xray Trojan-TLS TCP 443，不新增 AnyTLS、TUIC、Shadowsocks 等协议；保留 Hysteria2 UDP 443 与 VLESS Reality TCP 2053。为同一套三个节点生成 Clash/Mihomo YAML 与通用 URI Base64 两种订阅，并通过 Cloudflare Worker 提供统一入口和显式格式入口。

## 全局约束

- 不轮换现有 UUID、REALITY 密钥、Hysteria 密码和订阅令牌；只在旧 secrets 文件缺少时追加独立 `TROJAN_PASSWORD`。
- Trojan 使用 Xray、真实 Let's Encrypt 证书和 TCP 443；Hysteria2 继续使用 UDP 443，Reality 继续使用 TCP 2053。
- 未认证 Trojan 流量最多回落到 `127.0.0.1:8080` 的本地静态 Nginx，绝不回落或代理到外部网站。
- Xray 证书副本为 `root:xray`、目录 `0750`、文件 `0640`；续期 hook 同步证书并重启 Xray 和 Hysteria、reload Nginx。
- nftables 对 TCP 443 设置新连接全局限速和显式丢弃，保留默认拒绝、SSH 限速与现有端口规则。
- Clash 策略顺序为 `US-Hysteria2` → `US-Trojan` → `US-Reality`；`ChatGPT` 使用 `US-Auto`。
- URI Base64 订阅包含 Hysteria2、Trojan、VLESS Reality 三行分享 URI；文档明确旧 V2Ray Core/旧客户端不保证支持 Hysteria2 或 REALITY。
- 主令牌和备用令牌继续独立；所有订阅响应 `no-store`，错误路径不泄漏令牌或 KV 状态。
- 仓库和工作总结不得包含实际密码、私钥、UUID、订阅令牌或完整订阅 URL。

## Task 1：服务器部署代码

修改 `deploy/server-bootstrap.sh` 与 `scripts/vps-proxy.ps1`：

1. 以向后兼容方式生成或追加 `TROJAN_PASSWORD`。
2. 给 Xray 增加 Trojan TLS TCP 443 inbound、本地 fallback、证书复制与续期重载。
3. 生成含三个节点的 Clash YAML 和 Base64 URI 订阅文件。
4. Nginx 8443 提供两种显式备用订阅；订阅 URL 清单记录统一主入口及主备显式入口。
5. nftables 放行并限速 TCP 443；状态脚本将旧端口语义改为 Trojan。
6. 运行 Bash 语法、PowerShell 仓库校验及静态一致性测试，提交变更。

## Task 2：Cloudflare Worker 聚合入口

修改 Worker 并添加自动化测试：

1. `/<token>/clash.yaml` 返回 `clash-config`。
2. `/<token>/v2ray.txt` 返回 `v2ray-config`。
3. `/<token>/subscription` 根据明确 `target=clash|v2ray` 或客户端 User-Agent 选择格式；未知客户端默认 Base64，保证 V2Ray 类导入器不会收到 YAML。
4. 校验 `SUB_TOKEN` 必须是 64 位十六进制；仅接受精确路径及 GET/HEAD。
5. KV 缺失或异常统一返回不泄漏细节的 503；成功和错误响应都禁止缓存。
6. 单测覆盖两种格式、统一入口、HEAD、错误路径/方法、缺失 KV 和 KV 异常，提交变更。

## Task 3：文档、部署与验收

1. 更新 README、运维文档、安全说明和中文 worklog，明确协议、端口、订阅格式与兼容边界。
2. 在服务器部署且不轮换现有凭据；记录自动备份目录。
3. 验证 Xray/Nginx 配置、systemd、TCP/UDP 监听、nftables、证书权限和资源占用。
4. 用真实 Trojan 客户端完成经代理的 HTTP/HTTPS 请求，确认出口为当前美国 VM；确认现有两个节点服务仍 active。
5. 将两份订阅安全同步到 Cloudflare KV，部署 Worker；验证主统一入口、主显式入口、两个备用入口、错误令牌路径、响应头和 Worker/备用内容一致。
6. 重新运行仓库全量验证和分支审查后合并至 `main` 并推送。

## 回滚

部署脚本运行前会创建 `/root/proxy-stack-backup-<UTC时间>`。若 Trojan 或 Xray 验证失败，恢复该目录中的 Xray 配置、证书 hook、Nginx 配置、防火墙与订阅文件，执行配置测试后 reload/restart；Cloudflare KV 和 Worker 回退到部署前版本。任何回滚都不恢复已判定泄漏的旧凭据。
