# 双语 README 与项目门面

## 做了什么

把 README 从维护说明整理成了中英双语项目首页：有居中的标题、静态技术徽章、语言导航、Mermaid 架构图、客户端入口、维护命令、安全边界和文档地图。中文在前，英文提供同样完整的使用与维护说明，不只是一句简介。

## 为什么做

这个仓库已经不只是几段部署命令，还有真实排障、恢复脚本、测试和运行记录，值得有一个能把这些价值讲清楚的首页。之前交付的链接太多，用户容易不知道该复制哪个，所以这次把常用订阅压成两行，自动识别和备用入口收进折叠说明。

## 值得记住的决策和坑

华丽一点不等于把承诺写大。徽章只展示技术选型，不假装有持续可用率监控；100/100 请求写明日期和短时测试边界，浏览器与晚高峰未验收仍明确保留。也解释了三个协议仍是同一台美国主机，不是多国家节点或跨服务器高可用。

维护入口把检查、完整部署和凭据轮换的后果分开说明，提醒不要为了更新订阅重跑整套服务。实际 URL、密码、UUID、私钥和订阅正文一律不进入首页。这次只改 README 和这份记录，不操作服务器、节点配置或 Cloudflare。

检查时用 GitHub 的 Markdown 渲染接口确认了表格与折叠区块，四枚徽章均可访问，本地文档链接目标也存在。仓库安全扫描、16 项 Worker 测试和 7 项迁移测试通过；Markdown 换行改用显式标签，避免尾部空格影响 Git 格式检查。架构图保留为 GitHub 支持的 Mermaid 源码，不把语法块检查当作浏览器实测。

## 一句话亮点
