# Worker 聚合订阅入口

## 做了什么

给 Cloudflare Worker 补齐了 Clash YAML、V2Ray Base64 和统一订阅入口三条路由，并配上 Node 原生单测；仓库总校验现在会自动跑这些测试。

## 为什么做

用户需要同一枚私密 token 同时服务不同客户端，避免 V2Ray 类客户端误拿 Clash YAML，也要保证订阅内容与路径不能被缓存或意外泄露。

## 值得记住的决策、坑和技术点

- KV 键使用固定格式表映射，绝不从 URL、token 或 query 拼出来，避免把请求输入变成存储访问能力。
- 统一入口只有 `target=clash|v2ray` 才能覆盖；没有 target 时未知 UA 默认 Base64，这是兼容 V2Ray 导入器的安全默认值。
- 503 必须吞掉 KV 异常细节，并且错误响应也要带完整的禁缓存与安全头。Node 的 `--test` 不能直接接受目录路径，校验脚本需要指定具体测试文件。

## 一句话亮点

一枚 token 自动适配 Clash 与 V2Ray，订阅入口更好用，秘密边界依旧收得很紧。
