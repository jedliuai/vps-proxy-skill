# 首屏卖点卡片排版

## 做了什么

将首屏挤在一起的三个卖点改为 HTML 表格展示区：节点与订阅左右分列，经验介绍独占下一行。加入图标标题与段落留白，保留原有卖点措辞、徽章和导航。

## 为什么做

Markdown 连续行不会自动形成独立段落，导致 GitHub 把多句加粗文字挤成一团。长短不同的卖点也不适合等宽三列，因此使用两列加通栏的布局。

## 技术点与验证

使用原生表格、标题、段落和换行，不依赖自定义 CSS 或图片文字。只改 README 排版，不修改节点配置。执行仓库本地检查；本阶段未进行真实服务器测试，GitHub 实际显示仍受页面宽度影响。

## 一句话亮点

让三个卖点各有位置，而不是争抢同一行。
