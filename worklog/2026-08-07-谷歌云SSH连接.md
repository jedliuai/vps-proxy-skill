# 谷歌云 SSH 连接

## 做了什么

把这台 Windows 电脑连接到了 Google Cloud 上的 Debian 13 实例。确认了公网
SSH 端口可达，复用了本机已有的 `gcp` 密钥，在实例元数据中授权公钥，并建立
了 `my-proxy-vps` 这个好记的 SSH 别名。也确认了 WindTerm 的安装位置和导入方式，
同时在 Codex 中准备了可直接使用的远程终端。

## 为什么做

原先只有 Google Cloud 控制台中的实例信息，本机虽然已有 SSH 客户端和密钥，
但服务器并不信任这把密钥，所以会报 `Permission denied (publickey)`。目标是让
日常连接不再依赖浏览器临时 SSH，之后无论 PowerShell、WindTerm 还是 Codex 都能
使用同一套安全连接配置。

## 值得记住的决策、坑或技术点

- 只把公钥加入了单台实例的元数据，没有暴露私钥，也没有把权限扩大到整个项目。
- Google Cloud 的 Guest Agent 可能覆盖手工写入 `authorized_keys` 的内容，因此用
  实例元数据管理公钥更稳妥。
- 本机已有的 RSA 密钥可以继续使用，不需要为了这次连接再生成一把重复密钥。
- 实例只有约 1 GB 内存且当前没有 Swap，安装内存占用较大的服务前要先评估资源。
- 公网 IP 若未保留为静态地址，实例停止再启动后可能变化；变化后需要更新 SSH 配置。

## 一句话亮点

把浏览器里的一台谷歌云实例，变成了 PowerShell、WindTerm 和 Codex 都能一键直达的远程工作站。
