# 配置 2G Swap

## 做了什么

在 Debian 实例上创建了 `/swapfile`，容量 2 GiB，设为只有 root 可以读写，初始化并
立即启用。把它加入 `/etc/fstab`，让实例重启后也会自动启用，同时保留了修改前的
`fstab` 备份并验证了 systemd 生成的 Swap 单元处于 active 状态。

## 为什么做

这台 `e2-micro` 只有约 1 GB 内存，原先完全没有 Swap。运行软件安装、容器或偶发内存
峰值任务时，很容易触发 OOM 并被系统直接杀进程。增加 2 GiB Swap 可以给这种小机器
留出缓冲空间。

## 值得记住的决策、坑或技术点

- Swap 文件权限必须是 `0600 root:root`，避免其他用户读取可能被换出的内存内容。
- `/etc/fstab` 使用 `/swapfile none swap sw 0 0`，systemd 已生成并激活
  `swapfile.swap`，所以不依赖当前 SSH 会话。
- 修改前的备份在 `/etc/fstab.codex-backup-20260807-swap`。
- 当前 `vm.swappiness` 保持 Debian 默认值 60，没有擅自调整内核策略。
- Swap 是容量缓冲，不是性能升级；频繁使用 Swap 时仍应升级实例内存。

## 一句话亮点

给 1G 小主机加上 2G 安全气囊，让突发内存压力不再轻易把进程撞飞。
