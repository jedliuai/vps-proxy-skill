# 独立公开技能仓库

## 做了什么

按照新的分享方式，把已经脱敏的文件快照整理成独立的 `vps-proxy-skill` 仓库。公开版本采用新的初始提交，不复制私有仓库的 Git 数据库、本地运行资料、订阅交付文件或隐私备份。

双语 README 的项目名称、可复制提示词和公开访问说明，以及 AGENTS、SECURITY 和 Skill 的仓库定位同步更新。保留翻墙、VPN、科学上网、魔法等自然搜索关键词，公开仓库沿用与能力相符的描述和检索标签。

## 为什么做

私有前身在重写历史后，平台仍保留旧对象。让它继续保持私有，同时为公共工具箱建立独立历史，能够把分享代码和私人运维资料分开，而不再改动原仓库。

## 值得记住的决策和验证边界

只迁移被 Git 跟踪的脱敏快照，没有复制工作目录里的忽略文件，也没有 Fork 私有前身。Skill 的标识仍叫 `vps-proxy-builder`，部署脚本的内部名称和行为保持不变；仓库改名不是一次服务器升级。

发布前重新运行仓库扫描、静态检查、39 项本地测试和 Skill 格式校验，再审查唯一初始提交的全部对象、作者身份与文件引用。公开后另行核验未登录读取、GitHub CI 和原仓库的私有状态。隐私扫描是对已知标识和常见凭据模式的检查，不是对未知信息的绝对保证。

本次不连接 VPS，不部署 Cloudflare，不修改原私有仓库或原节点。历史记录里出现的旧名称和 Private 状态属于前身项目当时的情况，不能当作本公开仓库的当前状态。

## 一句话亮点

把仓库地址发给 Codex，就能把经过整理的搭建经验交给下一位使用者；分享方法，不分享秘密。
