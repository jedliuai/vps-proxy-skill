# 可发现性与版本入口优化

## 做了什么

把公开工具箱按“发现、理解、信任、使用、传播”重新检查了一遍。保留 vps-proxy-skill 名称，压缩 About 为中英文价值说明，把 Website 指向仓库快速开始，用 SSH Topic 替换宽泛的 GFW 标签，其余相关协议、客户端和 Codex 标签保留。

首页前部现在先回答适合谁、需要什么、能得到什么。英文说明独立成入口，删除原先重复的长英文段落。加入真实 CI 状态、固定版本克隆、预览版发布说明、纯说明性的交付示例，以及防止用户把订阅和完整日志贴进 Issue 的反馈模板。作者链接指向已有公开身份和项目列表，不捏造资历、背书或用户量。

## 为什么做

项目最值得传播的不是协议数量，而是把容易中断的部署过程做成可以检查和续接的流程。原先关键词和解释重复，英文读者要翻很久，也没有可引用的版本。新入口让读者先判断是否适合，再决定是否交给 Codex。

## 值得记住

本次只调整公开文档和仓库传播入口，未连接 VPS、修改协议逻辑或处理任何真实订阅。预览版是工具箱快照，不是升级服务器的要求。独立网站的 SEO 评分、结构化数据和关键词数量不应机械搬到 GitHub；不新增无用 SEO 文件，不承诺收录、排名或 Star 增长。

仓库尚无许可证，未代作者选择授权条款；这仍是后续扩大复用前应解决的事项。暂不制作没有验收证据的视频或稳定性图表，也不搭建需要维护的独立网站。

已测：16 项 Worker、12 项预检、4 项入口、7 项迁移测试全部通过，仓库秘密模式扫描、文件选择测试、部署静态检查及 diff 空白检查通过。未测：本次没有新 VPS 或家庭网络验收，也没有搜索流量提升的观测结果。发布状态以 GitHub Release 和对应提交的 CI 为准。

## 一句话亮点

让人一眼看懂、让 Codex 有据可做、让下一次维护有版本可循。
